## v0.4.0 shared encrypted storage

`src/object-store.js` separates filesystem and private S3 transport from the authenticated encryption layer. New transfer metadata records its backend; older GCM transfers default to filesystem storage. Upload, worker scan, download, deletion and backup use the same boundary. Reads enforce the configured object size, authenticate the full ciphertext before releasing plaintext, and require explicit S3 credentials. Optional checksums use the SDK's compatibility setting; file authentication remains mandatory AES-GCM.

`compose.s3.yaml` adds a private single-node Garage service with persistent ciphertext storage and generated ignored credentials/configuration. Multipart uploads use one buffered 5 MB part and abort on interruption; cleanup sweeps abandoned uploads and reconciles objects every minute. Startup checks all backends referenced by current transfers and retained copies. Migration authenticates source/destination, rejects conflicting objects, switches metadata conditionally and keeps originals until transfer deletion. Restore normalizes transfer metadata to the selected empty destination and verifies each recovered object.

Workspace controls now allocate the three-team owner limit atomically, guard quota and seat changes against stale plans/roles, and reject entitlement downgrades below usage. Downloads check current authorization after decryption, uploads check membership after streaming, and member removal immediately stamps recipient-grant revocation before updating individual transfer rows. Tests exercise concurrent workspace creation, interrupted S3 multipart uploads, permission changes during requests, backend readiness, conflicting migrations, reverse migration and cross-backend encrypted recovery.

README and operations instructions cover both local storage modes, backup stack detection, configuration retention and rollback compatibility. Production provisioning, redundancy, external identity/payments and independent acceptance gates remain outside the authorized local pilot scope.
